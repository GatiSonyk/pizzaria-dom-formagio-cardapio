# Pizzaria Dom Formágio na Serra — Cardápio Online

Aplicação responsiva para apresentar o cardápio, montar pedidos e encaminhá-los ao WhatsApp.

## Executar localmente

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
```

> Os preços e itens do cardápio devem ser conferidos com os materiais oficiais antes da publicação. O checkout via WhatsApp não substitui um sistema de pagamento online.
